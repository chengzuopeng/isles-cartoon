- 日期：2026-11-02
- 结果：2026-11-03 用户按默认定了下文「定下来的」几件事，进入阶段 2，先做 [1-2 牧场](../design/levels/1-2.md)
- 相关：[路线图](roadmap.md)「阶段 1」、[关卡 1-1](../design/levels/1-1.md)、[第一人称玩法](../design/gameplay.md)

阶段 0 和阶段 1 做完了，1-1 完整版能从头打到尾。这一页是给试玩用的：怎么开、重点看什么、定下来的事、还没做的。

## 怎么玩

```bash
pnpm dev
```

打开 http://localhost:5280 ，整备界面选「1-1 出发」，点出发。点一下画面锁定鼠标，Esc 解锁并暂停。

| 操作 | 键 |
|---|---|
| 移动 / 跳 / 冲刺 | WASD / 空格 / 左 Shift |
| 开枪 / 近战 | 鼠标左键 / 右键 |
| 技能 / 大招 | Q、E（E 槽 8 级解锁）/ R |
| 换枪 | 1 能量枪，2 特殊武器 |
| 拾取、开宝箱、点机关 | F（准星对着，2 米内） |
| 地图 / 静音 | M / N |

键位、鼠标灵敏度、视野角、眼高、镜头晃动都在整备界面的「设置」里改，改完的键位存在本机。按 ` 打开调参面板（开发版才有）。

打完一局，浏览器控制台里 `__game.runLog()` 能看到这局的命中率、受击来源、各区域用时，方便对照下面的问题。

## 重点看

1. **手感**：转镜头、移动、跳台阶、冲刺躲冲锋是否顺手；开枪三发一停、线圈一圈圈变暗看不看得出弹药
2. **晕不晕**：走路的镜头起伏、被冲锋兵撞到时的侧倾和减速（不再硬推镜头）、跳下高台
3. **预警看不看得懂**：地上的红色区域现在都竖起了光幕；射手的红线变亮时偏航和俯仰一起锁定，这时跳开或闪开能躲；Boss 冲锋的长条会高亮将要撞到的石头
4. **潜行**：敌人看到你先攒发现值，头顶出「?」，眼前有光锥；走进草丛和麦田镜头压低、四周是麦秆，矮个子的冲锋兵在草里头顶有灯
5. **画面**：手臂和枪（手臂和能量枪都用混元 3D 重做了，枪侧面朝镜头；弹药看枪管上 6 圈线圈，每发暗两圈；大招充满时枪口八片护套张开，打的时候左手托住枪管）、草地的野花和土路的石子、木墙顶的尖木桩、谷仓室内
6. **难度**：自动驾驶在普通难度下，「普通玩家」档 10 局过 9 局，「新手」档一局都过不了，主要死在风车坡北岸 4 个射手的步枪下；新手档改成简单难度能过 8 局。你自己打下来觉得哪一段太难或太简单

## 定下来的

2026-11-03 用户按默认定了下面几件事：

| 事项 | 定的 | 说明 |
|---|---|---|
| 眼高 | 1.5 米 | 设置里能在 1.2~1.5 米之间调，进草丛压低到 0.95 米。关卡的掩体和视线都按 1.5 米摆，调低只会看得更少 |
| 键位 | 照上表不变 | 近战只绑鼠标右键，键盘上不绑 |
| 脱战回血 | 留 | 5 秒没受伤、19.2 米内没有醒着的敌人，每秒回 30（满血 1000） |
| 代替翻滚的技能 | 震荡雷 | 朝准星扔，落点 3 米内的敌人眩晕 1.2 秒，规则见[第一人称玩法](../design/gameplay.md)「技能和大招」 |
| 手臂和枪 | 大小、位置不变 | 枪比 M1 大，侧面朝镜头，照目标图摆的。特殊武器的左手和各自的摆法先不做 |
| 掉下岛 | 不让掉 | 关卡四周一直挡人，岛边画栅栏和石头，不做掉下去算阵亡 |

## 还没做

- 近战还是单手抡，没有双手；9 把特殊武器的模型都已经用混元重做，但还没有左手和各自的摆法，都和能量枪一个拿法：霰弹枪的枪托会顺着前臂压在袖子上，火焰喷射器的罐子、火箭筒的后半截管子挡住画面右下角（2026-11-03 定先不做）
- 墙只有木栅墙换了形状，石墙、草垛墙还是平的；地标和场景件的 sim 高度还是俯视尺度（影响 1-2 以后的关）。跟着阶段 2 每关做，1-2 先做草捆墙和栅栏顶站不住
- 其余 4 个 Boss 的弱点和距离放大 1.6 倍，放到阶段 2 每关里做
- 性能：第一次进关的第一帧卡 300~590 毫秒（贴图上传和着色器现编），关内第一次打还有一两次 0.1~0.3 秒的卡顿，阶段 3 处理（[性能](../tech/performance.md)「测法」）
- 音效全是合成的占位
