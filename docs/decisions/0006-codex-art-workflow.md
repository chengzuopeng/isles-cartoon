# ADR-0006 在当前 Codex 会话生成二维素材

- 状态：已采纳
- 日期：2026-11-19
- 替代：[ADR-0004](0004-art-pipeline.md) 中的二维素材生成入口和 Blender 脚本维护方式
- 实现 PR：待确认

## 背景

项目由 Codex 接手，当前会话可以调用内置 ImageGen。旧流程从会话里启动独立的 Codex CLI 进程，图片生成和选图分在两个入口。

## 决策

- 在当前 Codex 会话内生成二维素材。选中的原图和完整提示词纳入 `art/`，运行时资源按现有格式进入 `public/assets/`。
- 新的独立透明素材使用生成图的 alpha。既有品红源图和分格脚本按原流程处理。
- Blender 脚本由 Codex 维护，继续使用既有挂点、刚性零件和 GLB 资产约定。混元 3D 是可选的网格来源。

出图、裁切和工作树下的 Blender 参数见[美术素材说明](../../art/README.md)。
