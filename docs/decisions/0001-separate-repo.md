# ADR-0001 独立仓库做第一人称卡通版试验

- 状态：已采纳
- 日期：2026-10-31

## 背景

用户看了一支美漫画风的街机式第一人称射击预告片（拆解见[参考预告片拆解](../reference/trailer-notes.md)），想把《碎星群岛》也做成这样，先试一试。之前在主仓库评估第一人称时，建议是在主仓库里加一个实验模式。用户选择新开一个目录 `isles-cartoon` 来做。

## 决策

- 新建独立仓库 `isles-cartoon`，和主仓库并排放在 `personal/codespace/` 下
- 主仓库（俯视版）照常推进，不为这个试验改动
- 代码和素材从主仓库拷过来改，不用 git 子模块，也不抽共享包；拷的时候在提交说明里记下来源
- 剧情、人物、世界观以主仓库为准，这里只写第一人称和新画风带来的改动
- 试验的成果（比如墨线渲染）以后可以搬回主仓库，由用户决定

## 考虑过的其他方案

| 方案 | 没选的原因 |
|---|---|
| 主仓库里加实验模式 | 渲染管线、输入、HUD、关卡都要大改，容易碰坏俯视版；两边的测试和截图基线会互相牵扯 |
| 主仓库开长期分支 | 主仓库还在频繁改（第 1 章刚收尾），长期分支合并成本高；两个版本也没法同时开着对比 |
| 抽一个共享的 sim 包，两边一起用 | 第一人称要把 sim 改成 2.5D，两边很快分叉；为一个还没定的试验抽包不值得 |

## 代价

- 代码有重复。主仓库修了 sim 的 bug，这边要手动同步（用到时再同步）
- 文档两份。剧情以主仓库为准，这边只摘要、不改写，避免两边打架
