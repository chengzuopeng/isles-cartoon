## 一句话

还是凯追着机器人强盗跑遍浮岛，只是这回从她的眼睛看出去：第一人称街机射击，画面像一本会动的美式漫画。

## 试验阶段回答了什么

M0、M1 原本要回答下面四个问题，再决定主线往哪走：

| # | 问题 | 结果 |
|---|---|---|
| 1 | 墨线卡通画风在 Three.js 里能不能做到目标图的水平 | 能。M0 做出了卡通明暗、描边、网点、手绘天空；近景还要按第一人称补细节，见路线图「美术」 |
| 2 | 新画风的性能够不够 | 开发机上流畅。1-1 缩减版约 730 个 draw call、150 万个三角形，超了 500 的预算，阶段 1 做按区域剔除；1080p 目标机器还没测 |
| 3 | 俯视版的战斗搬进第一人称以后好不好玩 | 用户定了全面转第一人称。眼高、键位、晕不晕在 1-1 完整版试玩时定 |
| 4 | 关卡、Boss、美术要补多少 | 第 1 章每关的第一人称改法和美术清单写在路线图里 |

## 设计支柱

1. **看得见，躲得开**。敌人的子弹是发光的弹丸，飞得不快；每一招出手前都有立体预警；身后的威胁有声音和方向提示。死了要知道是谁打的、下次怎么躲。这一条从俯视版原样继承
2. **往前冲才回血**。近战把机器人砸散架，它抢来的东西掉一地，捡起来回血。缩在掩体后面等回血不划算
3. **会动的漫画**。墨线、色阶、网点、手绘天空；每一下命中都冒拟声字，机器人被打得零件乱飞。画面要一眼看得清，最好还有点好笑
4. **每关一个新点子**。主仓库的差异化原则照旧：一关只引入一种新东西，同一关里每个区域的地形、机关、敌人组合都不一样

## 和俯视版比

| 方面 | 不变 | 变 |
|---|---|---|
| 剧情、人物、世界 | 全部沿用主仓库 | 敌人的台词改成漫画对白泡，看不见的人说话走字幕 |
| 战斗 | 子弹看得见、能躲；技能、大招、特殊武器、增益、掉落；各种敌人的分工 | 视角、俯仰瞄准、跳和冲刺、近战回血、打眼灯暴击 |
| 关卡 | 线性大地图、区域划分、锁门战、Boss 场、死亡重开本关 | 加高低差和视线遮挡，尺度放大 |
| 画面 | 主色、敌我颜色约定、各章色板 | 着色、描边、网点、天空、特效、卡片全部换 |
| 技术 | TypeScript + Three.js + Vite，sim / render 分层 | 逻辑从平面改成 2.5D，渲染管线新写 |

## 不做

- 联网对战
- 战术射击那一套：开枪即中、一枪爆头、后坐力管理、经济系统
- 写实画风
- 楼上楼下叠在一起的多层建筑（2.5D 做不了，见 [ADR-0002](../decisions/0002-2.5d-sim.md)）
- 新剧情、新角色
- 照搬参考预告片的任何具体内容（见[参考预告片拆解](../reference/trailer-notes.md)）
