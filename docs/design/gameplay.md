# 第一人称玩法

- 状态：草案。标「暂定」的数值和键位在 demo 里先按下文实现了，试玩后再定；实现时和下文不同的地方见文末「demo 实现记录」
- 更新：2026-10-31
- 相关：[愿景](vision.md)、[样机关卡 1-1](prototype-1-1.md)、[技术架构](../tech/architecture.md)；俯视版的规则见主仓库 `docs/design/game-design.md` 和它链接的子文档

这份文档只写第一人称带来的改动。没写到的规则（等级和加点、掉落权重、增益、技能树、精英词缀、锁门战、死亡重开本关、三星评价和挑战）都按主仓库。

## 定位

第一人称街机射击：节奏快、敌人成群、子弹看得见，靠走位、跳和冲刺躲招，靠近战回血。和战术射击（开枪即中、几枪就倒）不是一路，手感更接近老派的街机式第一人称射击。

## 尺度（暂定）

俯视版 1 格 = 1 米，凯身高 1.25 米、眼睛约 1 米，墙块 1.1 米。照搬到平视，墙挡不住视线，一眼能望出很远。第一人称版改成：

| 项目 | 俯视版 | 第一人称版 | 说明 |
|---|---|---|---|
| 1 格 | 1 米 | 1 米 | 不变，关卡还是字符画格子 |
| 镜头眼高 | — | 1.5 米 | 凯的模型是大头比例，第一人称看不到自己，眼高按正常身高取。样机里同时试 1.2 米 |
| 墙 | 1.1 米 | 3 米 | 挡人、挡子弹、挡视线 |
| 石头、草垛 | 0.75 米 | 1.2 米 | 半身掩体，见「掩体」 |
| 栅栏 | 0.55 米 | 0.9 米 | 挡人，不挡子弹 |
| 草丛、麦田 | 0.75 米 | 1 米 | 藏身规则照旧，不挡玩家视线 |
| 树 | — | 4~6 米 | 挡人挡子弹，树冠挡远处视线 |
| 交火距离 | 3~10 格 | 8~20 米 | 武器射程、弹速、敌人视野整体乘 1.5~2，样机里调 |
| 冲锋兵 / 射手 / 铁皮稻草人 | 按俯视比例 | 约 1.1 米 / 1.8 米 / 4.5 米 | 低头打冲锋兵、平视射手、仰视 Boss，俯仰瞄准才有用 |

## 操作（暂定，都能改键）

| 操作 | 键位 | 和俯视版比 |
|---|---|---|
| 移动 | WASD | 按视角方向走 |
| 视角 | 鼠标 | 锁定指针；灵敏度、Y 轴反转、视野角在设置里调 |
| 射击 | 左键（可按住） | 同 |
| 近战 | 右键 | 新增。俯视版右键是大招 |
| 大招 | R | 改键。没有换弹键（主武器自动装填，特殊武器不能装填），R 正好空着 |
| 技能 | Q / E | 同 |
| 冲刺闪避 | Shift | 俯视版的「翻滚」技能改成人人都有的基础动作 |
| 跳 | 空格 | 新增 |
| 切武器 | 1 / 2 / 滚轮 | 加了滚轮 |
| 拾取武器、开宝箱 | F | 准星的水平方向 35° 以内、2 米以内（宝箱再远 0.45 米）的目标里挑最对准的；上下只要别偏出 60°。1.2 米以内的不用对准，直接拿最近的（2026-11-02 做完） |
| 暂停 / 地图 | Esc / M | 同 |

键位都能在设置里改（`src/input/keymap.ts`），移动另有方向键、冲刺另有右 Shift 固定可用。

不做蹲：半身掩体按规则算躲住（见「掩体」），藏身靠草丛。

## 移动

| 项目 | 数值（暂定） | 说明 |
|---|---|---|
| 跑 | 6 米/秒 | 俯视版 3.8 格/秒，第一人称同样的速度显得慢 |
| 冲刺闪避 | 0.25 秒冲出 5 米，冲的过程中无敌；冷却 3 秒 | 继承翻滚的 0.25 秒无敌。方向按 WASD，没按方向键时往前 |
| 跳 | 起跳高度 1.3 米 | 能跳上石头和草垛（1.2 米），能跳过贴地的冲击波 |
| 台阶 | 0.5 米以内直接走上去 | 和敌人寻路用同一个限制 |
| 掉下岛 | 按阵亡算 | 也可以改成拉回最近的地面、扣一点血，样机里看玩家会不会常掉 |

镜头：跑动晃动默认关（设置里能开）；冲刺时视野角临时加 5°；落地时镜头轻微下沉。

## 射击

- 所有武器打出的都是看得见的弹丸，按俯仰角飞，不是开枪即中。狙击枪的弹丸极快，接近即中
- 打中机器人的眼灯算暴击，伤害 ×2，冒「叮！」；Boss 发光的弱点同样 ×2。没有一击必杀
- 散射变成锥形；榴弹、投掷物按仰角走抛物线；弹射枪碰到地面也会弹开
- 准星是屏幕中央的四角星。命中时闪一下，暴击闪金色，击倒时出一个小「×」
- 不做鼠标的辅助瞄准，以后支持手柄时再加

## 近战回血

俯视版战斗中回血靠回血包和补给点，脱战后慢慢回。第一人称版加一条更主动的路：

- 右键用枪托砸，前方 2 米、左右各 40° 以内的敌人都会挨到。伤害 150，击退 1.5 米，打断正在蓄力的招式，冷却 0.6 秒（暂定）
- 机器人生命低于 30% 时眼灯闪红、身上冒烟，表示「快散架了」。这时近战一下直接把它砸散；冲锋兵冲空发晕时也一样
- 砸散的机器人掉出它抢来的东西，走过去自动捡，每个回 8% 生命。第 1 章掉的是麦饼和苹果，正好对上「强盗只抢吃的」。以后每章换成那一章机器人在运的东西，比如第 2 章是给被困矿工送的水壶
- 用枪打死的照旧按俯视版的掉率掉回血包
- 脱战回血要不要留，样机里做成开关：开着按俯视版规则；关着时只能靠近战、回血包和补给点。试玩后定；简单难度一直开着

## 掩体

- 1.2 米的石头和草垛是半身掩体。敌人瞄的是主角胸口（离地 1 米），子弹打在掩体上；主角的眼睛在 1.5 米，能从上面探出来打
- 站在高处的敌人能越过半身掩体打到人，这就是高低差的意义
- 3 米的墙和房子是全身掩体
- 草丛：主角在草丛里时，敌人只有离得很近才能发现，规则同俯视版，距离按新尺度放大

| 大招「星光连射」 | 枪口展开成五瓣星形，1.2 秒内连射 12 发穿透的星形能量弹，方向跟着准星走。第一人称里枪的变形看得最清楚 |

## 武器

主武器和 9 把特殊武器的定位不变（主仓库 `docs/design/items-and-weapons.md`），射程按新尺度放大。第一人称要补的：

| 武器 | 第一人称要做的 |
|---|---|
| 能量枪 | 弹药直接显示在枪上：枪管上 3 圈线圈就是 3 格弹药，打一发暗一圈，装填时依次亮回来 |
| 霰弹枪 | 锥形散射，贴脸伤害最高 |
| 冲锋枪 | 随机散布改成锥形；连射时枪口上跳 |
| 狙击枪 | 按住左键慢慢收拢准星、视野拉近，松开开火，不占右键 |
| 榴弹炮 | 抛物线飞向准星指着的地面，落点画红圈，敌我都看得见 |
| 弹射枪 | 撞墙和地面都会反弹 |
| 火焰喷射器 | 近距离锥形喷射，火焰会挡住一部分视线 |
| 冰冻枪 | 敌人身上结冰的程度表示叠了几层 |
| 火箭筒 | 爆炸不伤自己，和俯视版一样 |
| 链式电枪 | 闪电在敌人之间跳，不用改 |

每把枪都要有第一人称的近景模型和动作：拿起、待机、开火、近战、收起。

## 敌人

打法、数值、警觉状态、小队配合按主仓库 `docs/design/enemies.md`，距离按新尺度放大。第一人称下的改动集中在「怎么让玩家看到、听到」：

| 敌人 | 俯视版的预警 | 第一人称另外加的 |
|---|---|---|
| 冲锋兵 | 地面长条 0.5 秒 | 蓄力时身体后仰、脚下冒火花、引擎轰鸣；冲空后发晕 0.9 秒，正好上去砸散 |
| 射手 | 红线瞄准 0.55 秒 | 红线从枪口直射到玩家身上，看得见那条指着自己的线；最后约 0.25 秒红线变亮、不再跟着走，同时一声上膛。红线变亮那一刻偏航和俯仰一起定死（2026-11-02 定的规则），之后横移、起跳、蹲进草里都躲得开；变亮前起跳没用，它会跟着抬 |
| 自爆兵 | 地面红圈 0.65 秒 | 引信火花和越来越快的哔哔声，声音带方位 |
| 盾兵 | — | 谷仓门盾挡住正面 120°；绕到侧面、跳起来从上面打、用爆炸都行 |
| 投弹兵 | 落点红圈 | 看得见炮弹往上飞再落下；落点红圈边缘加一圈竖起的红光 |
| 炮塔 | 炮管转向 | 三联散射按高度展开成扇面 |

通用：

- 地面预警（长条、圆、扇形、炮线、三联线）照样画在地上，边缘竖起 1 米高、往上渐隐的红色光幕，平视时也看得清（2026-11-02 做完）。召唤的出生圈、投掷物的落点圈按落点的地面高度画
- 爆炸带高度：爆点取爆炸物所在的高度（投掷物的落点、自爆兵脚下、炮弹打中的位置），往上够得着半径的 75%、往下 50%，站在高台上不会被台下的爆炸炸到；爆炸预警的圆圈也按爆点高度画、立光幕（2026-11-02）
- 包抄：同时贴身的冲锋兵名额照旧（普通难度 2 个），名额里最多 1 个在主角视野外（偏离朝向 70° 以上），身后的其他人先绕到视野里再上（2026-11-02）
- Boss 冲锋预警时，如果冲锋长条尽头是石头或大石头，那块石头套上一圈跳动的黄色光柱，提示「把它引过来撞这块」（引 Boss 撞石头时石头常在主角身后）
- 屏幕外的敌人开始蓄力时，准星周围出现指向它的红色弧线，同时播带方位的声音。主仓库的屏幕外威胁箭头（`src/ui/threat-indicators.ts`）的逻辑可以借
- 受伤时准星周围出现指向伤害来源的墨笔弧线
- 眼灯就是表情：平时圆点，发现玩家时变亮，生气时眯成一条缝，发晕时转圈，道歉时弯成笑眼（`art/concept/enemies-ch1.png`）
- 打死的机器人散架：零件顺着受击方向飞出去，几秒后消失。主仓库的模型本来就拆成了刚性零件，直接能用

### 草丛和麦田（2026-11-02）

- 麦田（农田主题的草丛）是代码生成的真麦秆，每格约 20 根，高 0.9~1.2 米，随风摆；草坡的草丛是绿色的长草
- 主角走进草丛时镜头从眼高缓缓压到 0.95 米，屏幕边缘浮出一圈麦秆剪影，下方显示「藏在草里」；走出来镜头再升回去。藏身的规则不变：草里的敌人只有 2.9 米内才看得见你
- 冲锋兵、自爆兵这种矮个子站在草里或贴着草时，头顶冒出一根细杆，顶上一盏红灯，高过麦秆；平时慢慢闪，进入战斗后快闪

### 发现（2026-11-02）

俯视版的敌人一看见主角就进入战斗。第一人称下改成先攒「发现值」，给玩家反应和潜行的余地：

- 看得见主角时发现值往上涨，离得越近涨得越快：贴脸（视野一半以内）约 0.4 秒满，视野边缘约 1.1 秒；正在找人的敌人（听到动静、刚跟丢）再快 1.6 倍。4 米以内直接发现
- 看不见时发现值慢慢退，从满退到空约 1.6 秒
- 发现值在涨时敌人停下，转头看向主角；满了才喊一声进入战斗，并按叫醒规则带醒同伴
- 头顶一个白底的「?」牌子，从下往上填成橙色，涨到七成变红、跳动；进入战斗后换成原来的「!」
- 每个没进入战斗的敌人眼前有一道淡淡的光锥，表示它朝哪边看，发现值越高越亮
- 数值在 `tuning.perception` 的 `noticeSeconds`、`noticeFade`、`noticeSuspicious`；被打中、听到枪声照旧直接进入战斗或起疑

## Boss

Boss 的招式和阶段按主仓库，第一人称下改的是尺度、预警和反击窗口：

- 体型放大到 4~5 米，仰视才有压迫感
- 预警做成立体的：冲撞的长条加光幕；震地改成贴着地面往外扩散的冲击波环，跳过去或者冲刺穿过去；散射的扇面在胸口高度飞来
- 硬直时弱点发光（铁皮稻草人是胸口的岛徽），打弱点 ×2
- 登场时出 Boss 卡（悬赏令样式，见[画风](art-direction.md)「卡片和字幕」），打完掉一地零件

1-1 铁皮稻草人的具体改法见[样机关卡](prototype-1-1.md)。

## 防晕

- 视野角默认水平 90°，设置里 75~110°
- 跑动晃动默认关
- 震屏强度沿用俯视版的设置项
- 准星一直显示；不做运动模糊
- 被打中时不再整个人被推出去：击退只保留三成（Boss 冲撞从约 1.8 米降到 0.5 米），改成短暂减速（最多 0.45 秒、移速 55%）加镜头往受击的另一侧轻轻一歪（最多约 3°，跟着震屏强度缩放）。刀片的「把人推出刀道」暂时保留全额推力，规则等 1-5 定（2026-11-02）
- 走上台阶时镜头高度用缓动跟上，不会一下跳 0.5 米

## 难度

三档难度照旧只改敌人的打法（主仓库 `docs/design/enemies.md`「难度」）。第一人称另加：简单难度下敌人子弹慢 15%、预警长 20%，脱战回血一直开着。

## 关卡规则

在主仓库的关卡规则和差异化原则之外，第一人称再加这几条：

- 每个区域至少有一处高低差（坡、台子、桥），第一个区域可以没有
- 区域之间用山坡、树林、房子挡住视线，不让人一眼望到底；下一个区域的地标远远就能看到，引着玩家往前走
- 星穹塔一直在远处看得见，当作方向的参照
- 关卡边缘是岛的悬崖，往外看得到云海和远处的岛；悬崖边摆矮栅栏或石头，不用看不见的墙
- 能进去的房子要有室内；进不去的门画成关着的
- 交火距离以 8~20 米为主；掩体之间的距离留在一次冲刺够得着的范围（5 米左右）

## demo 实现记录（2026-10-31）

尺度：主角跑速 3.8 → 6 米/秒。下面这些统一放大到 1.6 倍，生命、伤害、击退、各种时间、爆炸半径、近战够距不变：

- 小兵的视野和移动速度（冲锋兵 4.3、射手 3.5 米/秒等）
