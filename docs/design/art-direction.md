## 画面样板（2026-11-10）

用户觉得实机画面比参考预告片粗糙。逐帧对比后的结论（见[参考预告片拆解](../reference/trailer-notes.md)「逐帧再看」）：预告的模型并不精细，好看靠的是一套色、低角度硬光、粗墨线、平涂的天空、重网点和大一号的特效。`art/concept/` 的目标图是细节很多的插画，和这个方向不是一种画法，以后只用来对造型，不再当画面验收的标准；画面以预告片的手法和下面这张表为准。

第 1 章的色调叫「金色晨光」：暖金色的受光面、紫色的暗部和投影、青色的天。和预告第 1 章的黄昏橙红不是一套色，手法一样。数值集中在 `src/render/chapter-look.ts`，以后每章一份。

| 项目 | 现在的做法 |
|---|---|
| 太阳 | 压低到约 25°，从西南方照过来，投影又长又硬；环境光降到原来的一半 |
| 受光面 | 统一乘一层暖色（`litTint`），草地、木头、石头都往金色靠 |
| 暗部和投影 | 先去掉一半本色再染紫（`shadowTint`），不同东西的暗部是同一种紫 |
| 网点 | 格子从 6 像素放大到 8 像素，颜色更深；烟团单独一套，几乎整团都是网点 |
| 墨线 | 外轮廓 2.2 → 3.4 像素，内部转折 1.1 → 1.6 像素；45 米外才开始变细，内部线画到 110 米 |
| 天空 | 手绘全景图换成程序画的平涂云：云两个色（亮面奶白、底面淡紫）、硬边带墨线，天分两段青色，地平线一条暖色，有太阳圆盘 |
| 地面 | 土路上的石子、裂缝和草地上的草叶笔触加粗加深，肉眼看得见是画出来的线；草丛模型不再描边，免得一片黑线 |
| 围合 | 地图东西两侧每 5 米一棵 12~15 米的高树（只是画面，不挡人），挡住岛外的空白，也在地上拉出长影子 |
| 镜头 | 边缘色差加大；震屏的同时色差跟着脉冲一下；冲刺和近战命中时屏幕边缘出白色速度线 |

特效：

| 项目 | 现在的做法 |
|---|---|
| 命中 | 十几条发光的橙黄长线向四周迸开（暴击更多、偏白），带泛光 |
| 打在墙上 | 几条火花加一小团烟 |
| 击倒 | 零件飞出去（已有），加三十条火花和几团网点烟 |
| 爆炸 | 一圈黄白闪光，6~7 个带墨线的橙黄火球，随后十几团深褐色的网点烟球胀开、停一秒多再缩没，外加四五十条火花 |
| 木箱碎 | 几团浅褐色的烟 |

2026-11-10 用户看过样板：色调可以；敌人放大到和人差不多高（见[第一人称玩法](gameplay.md)「尺度」）。放大以后敌人投真实的影子（有雾的关卡还是脚下一个圆影），埋伏在草里的先蹲着、冲出来时站起。

还没做的：

- 敌人的受击闪白、拟声字叠成一摞、枪口火光换成带墨线的大星形、回血的绿色光带，这几样还是原来的

## 一句话

像一本会动的美式漫画：深色墨线勾边，明暗只有两三档，暗部铺网点，天空是手绘的，打中东西会冒字。

## 着色

| 项目 | 规定 |
|---|---|
| 明暗 | 漫反射压成 3 档：亮、中、暗。档和档之间是硬边，只留 1~2 像素的过渡防锯齿 |
| 暗部 | 偏冷的蓝紫，不发黑。每章一个暗部色，第 1 章暂定 `#5a5f8a`，在暗档里混入约 35% |
| 网点 | 只在暗档里铺：45° 排列的圆点，越暗点越大；点的颜色是表面颜色压暗一档，不用纯黑。角色身上的网点比场景细、比场景淡，保证角色好认 |
| 高光 | 金属和眼灯有一块硬边的白色高光；布、木头、石头没有 |
| 主光 | 左上方的暖光，和俯视版一样 |
| 自发光 | 眼灯、能量弹、星核碎片、Boss 弱点发光，带一点柔和的泛光 |

## 线

| 项目 | 规定 |
|---|---|
| 颜色 | 暖黑 `#1d1714`；远处的线往天空色淡化 |
| 外轮廓 | 1080p 下 2~3 像素；角色和敌人比场景粗一档 |
| 内部转折 | 1~1.5 像素，按表面朝向的变化画 |
| 距离 | 30 米以外变细变淡，60 米以外只留外轮廓 |
| 手绘线 | 木板纹、石缝、砖缝、铆钉边、草叶画在贴图里 |
| 不画线的 | 天空（云的线画在天空贴图里）、粒子、拟声字、HUD |

## 天空和远景

- 每章一张手绘天空。第 1 章是晴朗的早晨：顶上饱和的青蓝，往地平线过渡到暖奶油色，大朵积云带墨线和两档明暗
- 岛的边缘外面是云海，远处是别的浮岛和瀑布；星穹塔一直在远处，当方向的参照
- 远处的东西往天空色淡化，线也跟着淡

## 配色

沿用主仓库的全局颜色约定和各章色板：玩家青 `#5ff0ff`、危险红 `#ff3b30`、敌人眼灯琥珀 `#ffb02e`、回血绿 `#52e07a`、弹药黄 `#ffc94d`、6 种增益色。新加的：

| 用途 | 颜色 |
|---|---|
| 墨线 | `#1d1714` |
| 纸色（卡片、字幕底、对白泡） | `#f6ecd6` |
| 第 1 章暗部色 | `#5a5f8a`（暂定） |

可读性规则照旧：地面低饱和、角色高饱和；主角的子弹偏青白，敌人的偏红橙。网点不能把角色铺花。

## 第一人称手臂和枪

- 平时只露右小臂和手，大招时左手从下面伸上来托住枪管（近战现在还是单手抡）
- 枪侧面朝着镜头，枪口指向画面中间偏左，能看到枪管上的 3 圈线圈；手臂从右下角伸进来
- 造型照凯的设定（[设定摘要](setting.md)「凯」）：橙色飞行夹克的袖子，右袖黑底白星圆章，黑色露指手套；能量枪以能量枪三视图为准，枪管上 3 圈青色线圈，枪口橙色，枪口护套是 5 片瓣片，大招时张开成五瓣星
- 这是全游戏离镜头最近、出现时间最长的东西，精度最高：线稿贴图、细节和动作都比场景高一档
- 动作：拿起、待机（轻微呼吸）、走路摆动、开火（3 连发后坐，每发暗一圈线圈）、近战（双手抡枪托）、大招（枪口张开成星）、换武器、受击（手臂抖一下）

目标图：`art/concept/viewmodel-kai.png`

## 敌人

- 造型和主色不变（主仓库 `docs/design/characters.md`），按平视重新检查正面：眼灯、胸口的岛徽、手里的武器
- 眼灯是唯一的表情来源，5 种：平静（圆点）、警觉（亮圈带闪光）、生气（眯成斜缝）、发晕（转圈）、道歉（弯成笑眼）
- 第 1 章的装扮：关节里塞稻草、麻袋补丁、绳子、背着麦袋
- 被打散架：零件顺着受击方向飞出去，螺丝和小铁片多一些

## 拟声字

- 中文，手写感的粗体字，深色描边加硬投影，带一个小爆炸框或速度线
- 同时最多 3 个；在命中点附近弹出、放大、稍微转一点，0.4~0.6 秒后消失
- 字和颜色：

| 事件 | 字 | 颜色 |
|---|---|---|
| 能量弹命中 | 啪！ | 青到白 |
| 近战 | 哐！ | 橙 |
| 爆炸 | 轰！ | 黄到橙红 |
| 子弹打在盾上 | 当！ | 钢蓝到浅灰 |
| 打中眼灯（暴击） | 叮！ | 金 |
| 机器人散架 | 哐啷啷 | 锈红 |

- 每章可以加几个本章特有的字，比如第 1 章的羊「咩～」
- 实现：先用网页字体在 HTML 层画，候选是 Google Fonts 上站酷系列的中文字体（OFL 许可），用之前先问用户、登记进 `art/CREDITS.md`；效果不够再换成 Codex 画的手写字贴图，`art/concept/sfx-lettering.png` 就是这种做法的样子，背景是纯品红，能直接抠

目标图：`art/concept/sfx-lettering.png`

## 卡片和字幕

卡片用我们自己剧情里的母题：凯是赏金猎人，晨风镇的悬赏板贯穿全篇。

| 卡片 | 样子 |
|---|---|
| Boss 登场卡 | 一张钉上去的悬赏令：发黄的纸、Boss 的画像、名字、一句吐槽的「罪名」和赏金。打赢后盖一个「已结」的红章 |
| 章节卡 | 主仓库第 1 章标题卡的插图改成漫画风，左边写「第 1 章 / 晨风镇 / 借麦子的强盗」 |
| 机制提示卡 | 第一次遇到新机制时，屏幕一角滑出一张钉着的小纸条，一句话说清楚 |
| 字幕 | 底部居中：左边是说话人的立绘头像，名字写在一块小木牌上，台词在纸色底上 |
| 对白泡 | 镜头里看得见的敌人说话时，头顶冒漫画对白泡，尾巴指向它 |

标题和卡片上的中文字用和拟声字同一套手写感的粗体字。不用参考预告片的卡片版式、配色和字体。

## 统一风格描述

用 Codex 出图时每次都带上这段。Codex 用英文原文，中文是意思：

> Rendering style (most important): an original comic-book look, like a living comic panel. Bold black-brown ink outlines with varying weight: thick on outer silhouettes, thinner on interior creases, thinning with distance. Hand-drawn ink hatching and grain lines on wood, stone and metal. Flat cel shading in 2-3 hard tone steps. Cool blue-violet shadows, never pure black, filled with fine halftone dot screens. Warm key light from the upper left. Punchy saturated colors, with the ground less saturated than the characters. Glowing emissive accents (amber eye lamps, cyan energy) with soft bloom. Faint paper grain. Chunky, rounded, slightly exaggerated proportions. All designs are original; do not imitate any existing game, studio, character, logo, card layout or typography.

> 原创的美漫风格，像一格会动的漫画。深褐黑色墨线，粗细有变化：外轮廓粗，内部转折细，越远越细。木头、石头、金属上有手绘的排线和纹路。平涂的赛璐璐明暗，只有两三档，硬边。暗部是偏冷的蓝紫色，不发黑，铺细网点。主光在左上方，暖色。颜色饱和、有冲击力，地面比角色灰一些。眼灯、能量这类自发光的东西带柔和的泛光。淡淡的纸纹。造型粗短圆润，略夸张。全部原创，不模仿任何已有的游戏、工作室、角色、标志、卡片版式和字体。
