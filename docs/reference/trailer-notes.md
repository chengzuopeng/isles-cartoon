# 参考预告片拆解

- 更新：2026-11-10
- 来源：用户提供的一支 46 秒的游戏预告片，实机画面，游戏名《Iron Curtain Call》。视频和截图都不进仓库；2026-11-10 用户让放进工程，本机在 `reference-video/`（`trailer.mp4`、`frames/` 抽帧、`sheets/` 九宫格总览），用 `.git/info/exclude` 忽略
- 只看了画面，没听声音。2026-10-31 每秒抽 2 帧；2026-11-10 重新抽了一遍（前 16 秒每秒 4 帧，后面每秒 2 帧，共 124 帧），补了下面「逐帧再看」一节

这份记的是它用了哪些手法、我们借哪些。具体内容一律不照搬。

## 预告的结构

1. 前 16 秒演示第 1 章：武器、近战、回血规则、敌人的冷笑话、第一个 Boss
2. 一张大字卡，意思是「12 章，每章一个馊主意」
3. 9 个章节各闪 1~2 秒
4. 5 个 Boss 的登场卡
5. 主视觉和标题

以后做 Steam 预告可以用同样的结构：核心玩法 → 章节数大字卡 → 章节快剪 → Boss 登场 → 主视觉。

## 玩法

- 第一人称，屏幕上一直有主角的手和枪；敌人成群，爆炸很大，节奏快
- 血和护甲要主动去拿：近战揍敌人回血，把敌人点着加护甲，逼着玩家往前冲
- 武器不多，但每把都夸张、带一个梗；近战是一记很大的拳头
- 竞技场式的关卡，有掩体、有高低差，能站在桥上、脚手架上往下打
- 每章一个点子，比如雪地里停下来会结冰、月球上低重力、在高空飞艇上打
- Boss 都是巨物，第一人称仰视很有压迫感；弱点用发光的圈标出来

## 画面

- 美漫墨线风：模型都有粗细变化的黑色外轮廓，砖缝、窗框也是手绘线条，像会动的漫画分镜
- 阴影和烟雾里有网点；爆炸是一团团卡通烟球，机器人被打得散架、零件乱飞
- 天空是手绘的漫画云，明暗很硬，每章换一种色调
- 光照偏戏剧化：暖色主光，发光的东西都有泛光，画面边缘有一点红青错位的色差
- 场景很密，招牌和标语几乎都在开玩笑
- 画风本身也拿来演出：有一章开头整个画面先变成黑白报纸印刷，再转回彩色

## 文字和演出

- 命中时冒英文漫画拟声词，几个叠在一起往外弹，词还跟着章节的梗走
- 敌人边打边说冷笑话，屏幕下方出带圆形头像和名字的字幕
- 四种卡片：机制提示卡、章节卡、Boss 登场卡、Boss 战提示；奶白色粗衬线字加深色投影
- 预告里没看到血条和准星，可能是剪掉了

## 基调

政治讽刺加冷笑话，拿冷战、选举、军火、经济政策开涮。

## 借什么

都是这一类游戏通用的手法：

- 墨线加网点的着色、手绘天空、卡通烟球、机器人散架
- 命中冒拟声字，我们用中文
- 卡片式的演出：章节卡、Boss 卡、机制提示卡。版式自己设计，用悬赏令做母题（见[画风](../design/art-direction.md)「卡片和字幕」）
- 每章一个点子：主仓库本来就是这个原则
- 街机式第一人称的节奏：成群的敌人、看得见的子弹、靠近战回血逼玩家往前冲
- 敌人边打边说笑话：我们的机器人本来就会道歉

## 不借什么

- 主角的手：白手套配绿袖子。我们是凯的橙色夹克袖子和黑色露指手套
- 卡片的版式、配色和字体
- 政治讽刺的题材
- 具体的角色、Boss、武器和梗：长着脸的火车、巨型大妈、套娃元帅、开坦克上高速的将军、包成礼物的火箭筒、收银机造型的枪、发解雇单的枪、弹鼓像胶片盘的冲锋枪、叫「外交官」的霰弹枪
- 「把敌人点着加护甲」这条规则。我们只做近战回血，第二条资源线是已有的大招充能
- 笑点从我们自己的剧情里来：会道歉、留借条的强盗，只会说「嘣」的嘣嘣，嫌自己赏金太低的凯

## 逐帧再看（2026-11-10）

用户觉得我们的实机画面比预告粗糙，对着抽帧重新看了一遍。最重要的一条：**预告里的模型并不精细**，房子是方盒子，地面是平面，敌人和枪都是大色块。它好看靠的是下面这些，不是模型细节。

### 画风

| 项目 | 预告里的做法 |
|---|---|
| 配色 | 每章只用三四个色相。第 1 章是黄昏：橙红的受光面、紫色的暗部和投影、暗橙的天，再加敌人的红和弹道的黄。草地绿、天蓝这种「本色」基本不出现，所有东西都被场景光染过 |
| 光 | 太阳很低，投影又长又硬，颜色是饱和的紫，不是灰。地上一半亮一半暗，明暗交界线本身就是构图 |
| 围合 | 战斗发生在广场、车站、街道里，四面是两三层楼的房子，画面七成以上被立面填满，天空只占顶上一条。很少有一眼看到地平线的镜头 |
| 地面 | 整片砖地，每块砖有墨线，掠射角下纹理一直铺到远处；砖的颜色有两三种深浅随机 |
| 墨线 | 粗而均匀的黑线，1080p 下外轮廓 3~4 像素，远处的房子也有线；窗框、砖缝、招牌边框这些内部线靠贴图画，量很大。手里的枪和手套线最粗 |
| 天空 | 平涂的卡通云，两个色、硬边、带墨线，和 3D 场景是同一种画法，没有渐变和笔触 |
| 网点 | 用得很重：烟、暗部、爆炸的边缘都是肉眼可见的大网点，烟团几乎全靠网点画 |
| 自发光 | 亮着的窗户、路灯、信号灯、敌人的眼睛都发光带泛光，黄昏里很显眼 |
| 镜头后处理 | 画面边缘一直有红青错位，爆炸和重击的那几帧错位加大到整屏；有暗角 |
| 密度 | 招牌、横幅、脚手架、碎砖堆、路障、油桶，几乎每面墙都有字 |
| 手和枪 | 占画面右下约四分之一，纯色加粗线，白手套在任何背景上都跳得出来 |
| 敌人 | 和人一样高或更高，饱和的红色、眼睛发光，和背景的橙紫拉得开 |

### 打斗特效

| 项目 | 预告里的做法 |
|---|---|
| 枪口火光 | 带墨线的黄色多角星，1~2 帧；重武器是占四分之一屏的白色星爆加一个圆环 |
| 弹道 | 发光的黄色短线，看得见飞行 |
| 命中火花 | 一次命中迸出三五十条橙黄的长线，向四周放射，带泛光，持续好几帧；连射时半个屏幕都是火花 |
| 受击闪白 | 敌人整个变成白色剪影加墨线，1~2 帧；冻住是淡蓝白，另一种状态是整身金色 |
| 拟声字 | 黄和橙的斜体字，带深色描边，出现在命中点上方；不同事件不同的词，连续命中时四到六个叠成一摞。还有状态字（「护盾没了」这一类） |
| 爆炸 | 先是带墨线的橙黄火球，随即变成深褐色的网点烟团，膨胀到三分之一屏，停留一秒多；飞出去的每块碎片后面拖一条一团团的烟轨；地上留着火 |
| 散架 | 头、手套、身体整块飞出来，有的直接朝镜头飞；零件大、数量不多、弹跳明显 |
| 近战 | 一只占画面中央的大拳头，白色放射线加一个往外扩的黄色圆环，配「SOCK!」「WALLOP!」；敌人被打成一团网点烟 |
| 掉落和拾取 | 回血的东西落地后是地上一个发光的绿圈；捡的时候变成绿色的光带飞向主角，划过半个屏幕 |
| 镜头 | 重击和冲刺时屏幕边缘出白色速度线；爆炸时镜头抖、歪，有一两帧动态模糊和闪白 |
| 弹壳 | 开枪时弹壳从枪边跳出来 |
| 换弹 | 火箭筒装弹看得见手把火箭塞进去 |

### 和我们现在的差别

- 我们的目标图（`art/concept/style-frame-1-1.png`）是一张细节很多的插画，和预告的「平涂加粗线」不是一种画法。按它验收会把力气花在模型细节上，方向偏了
- 我们用的是正午的平光和各物体的本色（绿草、蓝天、红谷仓、黄草垛），没有统一的色调；预告是低角度的硬光加一套色
- 我们的关卡是开阔的田野，画面里大半是天和平地；预告把战斗放在被房子围住的地方
- 地面和墙是纯色，没有画出来的线；墨线偏细，远处就淡没了
- 天空是有渐变和笔触的手绘图，和平涂的 3D 场景不是一种画法
- 特效的量级小一档：火花少而短，爆炸的烟小、散得快，网点几乎看不见，没有屏幕速度线和整屏的色差脉冲
